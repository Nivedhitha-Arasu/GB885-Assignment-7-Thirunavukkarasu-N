# Bramble Coffee Roasters — Ops Report

The network currently has 40 cafés.

## Purpose

Calculates the company-wide monthly coffee waste rate from the café logs.

## Data Source
The data includes the logs from the cafe as a csv file, read into a pandas dataframe 

## How to run
1. Open the *.ipynb file in Google Colab with the link provided at the top of the file.
2. Run cells from top to bottom.
